# Logisim Evolution

## Introduction
**Logisim Evolution** is a free and open-source digital logic circuit design and simulation software. It is used to create, test, and analyze digital circuits using a graphical interface without requiring physical electronic components. It is widely used in digital electronics, computer organization, and computer architecture courses.

## Features
- Graphical drag-and-drop interface.
- Supports combinational and sequential logic circuits.
- Provides logic gates such as AND, OR, NOT, NAND, NOR, XOR, and XNOR.
- Includes flip-flops, registers, counters, RAM, ROM, multiplexers, decoders, and encoders.
- Real-time circuit simulation.
- Displays values in Binary, Decimal, Hexadecimal, and Octal.
- Supports hierarchical design using subcircuits.
